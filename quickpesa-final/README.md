# QuickPesa

Kenya's professional crash game — Aviator style.

## Features
- Provably Fair Crash Game
- Dual Betting System
- Auto Cashout
- M-Pesa, Airtel, Bank, Crypto deposits
- Phone & Email login/register
- Real-time chat
- PWA ready

## Deploy
```bash
npm install
npm run build
vercel --prod
```
