# QuickPesa

Kenya's fastest crash game — built for mobile, powered by provably fair technology.

## 🚀 Tech Stack

- **React 19** + TypeScript
- **Vite** (build tool)
- **Tailwind CSS** (styling)
- **Zustand** (state management)
- **Framer Motion** (animations)
- **Lucide React** (icons)

## 📱 Features

- **Provably Fair Crash Game** — Cryptographically verifiable rounds
- **Dual Betting System** — Place two bets with different strategies
- **Auto Cashout** — Set target multipliers for automatic cashouts
- **M-Pesa Integration** — Deposit and withdraw via mobile money
- **Live Chat** — Real-time player interaction
- **Round History** — Track last 50 crash points
- **PWA Ready** — Installable on mobile devices

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
